# Generative temporal graph repair

Active research project: learn transferable restoration of event participation and fragmented identities from generated operational histories. The intended application is traceability in purchasing, loan processing, and logistics.

The accepted [research proposal](../Temporal_Graph_Papers_2024-2026/analysis/new_idea_20261015/PROPOSAL.md) and [novelty audit](../Temporal_Graph_Papers_2024-2026/analysis/new_idea_20261015/NOVELTY_AUDIT.md) are the starting point. Results, including failed hypotheses, determine the final claims. No trained-method benefit or publication readiness is established yet.

Read [RESUME.md](RESUME.md), [STATE.json](STATE.json), and [docs/TASK_CONTRACT.md](docs/TASK_CONTRACT.md) before continuing. The completed forecasting paper remains a separate project. Its raw public data can be read; its source, labels, results, and release artifacts must remain unchanged.

The paper will contribute a bounded, reusable factory increment if the baseline gate supports model development. The complete general dataset factory is outside this paper's scope. RF is excluded from the experiments.
