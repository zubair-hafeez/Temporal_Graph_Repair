# Snapshot verification

- All current project files, hidden files, ignored files and original Git metadata included.
- Every archived regular file SHA-256 verified against the source inventory.
- Archive membership, symbolic-link targets and POSIX permission bits checked.
- Every split archive checksum independently checked.
- Source sizes and modification times checked for changes during preparation.
- Working files and reachable Git history scanned for common credential signatures; this is a bounded automated scan, not a guarantee of absence.
- Original research folders were not modified.
- No experiments were rerun and no scientific claims were independently revalidated.
- Remote upload and remote verification are recorded separately in the publisher receipt.
- Commit author Codex Backup identifies the automated packaging operation.
